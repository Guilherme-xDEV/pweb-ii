## Repositória Da Discipina - Programação Web II

4º semestre do curso de ADS | Tauá CE 2026

### Objetivo da Disciplina

desenvolvimento da programação para front-end das aplicações WEB integrado com a programação do back-end.

* Construir interfaces Web utilizando modelos e métodos consolidados pelo
mercado e indústria;
* Utilizar linguagem de programação front-end baseada em código aberto
para
desenvolvimento de aplicações WEB;
* Investigar métodos, técnicas, práticas, arquiteturas e tecnologias para o
desenvolvimento de sistemas de software disponibilizados sobre a
plataforma Web;
* Conhecer os principais padrões de projetos utilizados em aplicações
comerciais;
* Desenvolver aplicações web integradas com back-end.

### Lista De Linguagens e Tecnologias

* JavaScript
* TypeScript
* React
* Node
* Angular
* Bibliotecas de estilização
* Gerenciadores; npm, bun, nvm
* Versionamento
* Integração com banco de dados
* Plataformas de deploy da web
